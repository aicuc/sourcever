# Before You Build

**Don't build from zero. Build from where humanity stopped.**

别从零开始，从人类已经走到的地方继续。

一个可本地运行的中文能力图谱 MVP：输入想做到的事，先看底层需求、历史分叉与演化原因，再看成熟方案、一手来源、获取条件和仍值得探索的问题。

```text
Want → History → Solutions → Sources → Access → Frontier
```

## 立即运行

需要 Node.js 22.9+。应用没有第三方运行依赖。

```bash
git clone https://github.com/aicuc/before-you-build.git
cd before-you-build
npm start
```

打开 http://127.0.0.1:4173 。默认只监听本机。

```bash
npm run check  # 图谱、引用、ID、关系完整性
npm test       # HTTP、输入边界、模型契约与数据测试
```

## 已实现

- 七个公开案例：网站搭建、团队协作、云存储、代码托管、视频会议、知识管理、在线支付。
- 需求抽象、可点击的演化节点与因果连线、分叉/汇合、失败路线。
- 资源筛选、官方来源、身份条件、地区及时间信息缺口、获取步骤。
- 成熟/发展中/待验证问题分类。
- 可编辑 MVP、PRD、研究任务模板和 Markdown 导出。
- 响应式中文界面、键盘操作、可选 AI 分析接口。

## 两种分析模式

**精选案例（默认）**：用关键词匹配编辑案例，不调用模型、不联网搜索。不支持的输入会明确提示未收录；匹配到案例也不会宣称是定制研究。所有数据随项目运行，不上传用户输入。

**AI 草稿（可选）**：复制 `.env.example` 为 `.env`，设置 `AI_BASE_URL`、`AI_API_KEY` 与 `AI_MODEL`，重启服务。使用支持 Chat Completions JSON 对象模式的模型服务。对未收录需求自动调用；已匹配的输入也可点击“针对输入进行 AI 分析”。密钥仅存在服务端，请勿提交 `.env`。

这会把输入发送到你配置的模型服务。当前模型没有联网检索工具，结果始终标注为“未经核验的研究草稿”。模型价格、引用及历史判断不能视为已验证事实。生成结果需通过结构和引用校验，否则展示可重试错误；单次超时 90 秒，同时最多两个模型请求。

本次交付验证了模拟服务的成功与失败路径；未配置真实模型密钥，未进行付费端到端调用。

## 仓库结构

```text
SKILL.md                  可在 AI 编程助手中使用的方法论 Skill
server.mjs                本地 HTTP 服务与可选模型适配器
web/                      浏览器界面、样式、数据契约
data/                     图谱实体、关系和精选案例
docs/                     方法论、数据模型、理念、实施与验证记录
examples/                 七个由当前数据生成的 Markdown 公开案例
scripts/validate.mjs      图谱一致性检查
tests/                    Node 原生测试
```

## 作为 Skill 使用

仓库根目录 `SKILL.md` 是入口。可将本仓库复制到支持目录型 Skill 的助手的 `skills/before-you-build/` 下；至少保留 `SKILL.md`、`docs/methodology.md`、`docs/data-model.md` 和 `examples/`。也可以直接让助手阅读根目录 SKILL.md 后对你的需求应用该方法。

Skill 不会自动申请权益、创建外部仓库或发布私人想法。使用的工具取决于宿主提供的能力。

## 数据质量与边界

这不是完整历史数据库，也没有全网实时爬虫。节点中的时间大多是路线概括，不代表首次发明年代；来源说明当前能力不等于证明历史因果。已查阅来源标有日期，未核验入口明确显示待复核。只有团队协作、建站、代码托管和知识管理目前收录了有官方公告的停止产品案例，其余保留缺口。

“创新边界”是编辑推导的假设，不能当成已证实的市场空白。Access 表示合法获取路径，并非法律意义的法定权利，也不保证通过申请。费用、资格、版本、地区限制需要在使用前再次核对。

## 运行与发布

此版本面向本机使用；不带用户认证、共享限流或多租户隔离。默认 `HOST=127.0.0.1`。如果将带模型密钥的服务发布到外网，应先增加认证、配额和反向代理。静态文件采用显式白名单，不会暴露源代码或环境文件。

公开仓库：[aicuc/before-you-build](https://github.com/aicuc/before-you-build)。贡献时只提交公开案例与代码，检查不含私人想法或密钥。

参见 [方法论](docs/methodology.md)、[数据模型](docs/data-model.md)、[贡献说明](CONTRIBUTING.md)。
